# Sesión 2026-06-19 12:07

## Objetivo

Aclarar cómo exportar la evidencia original `CLIENT_EVENT` desde Velociraptor
para la repetición controlada.

## Resultado

- La vía recomendada para la primera campaña es la GUI de Event/Client
  Monitoring, seleccionando el cliente, artifact, source y ventana UTC.
- No se debe exportar SOC_v3 como sustituto de las filas `CLIENT_EVENT`.
- La exportación por comando es posible desde la máquina servidor mediante VQL
  `monitoring()`, pero requiere confirmar:
  - ruta del binario servidor;
  - ruta de `server.config.yaml`;
  - `ClientId` actual;
  - sintaxis ofrecida por `query --help` en Velociraptor 0.75.6.
- El `ClientId` histórico `C.364907172793f8c7` no se asume vigente sin
  comprobarlo en la GUI.

## Limitación

No existe copia local del binario ni de `server.config.yaml` en el host TFM.
La documentación web oficial no estuvo accesible desde la sesión, por lo que no
se declara validada localmente la línea CLI.
