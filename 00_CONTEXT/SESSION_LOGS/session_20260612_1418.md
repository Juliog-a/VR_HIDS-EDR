## Decisiones tecnicas

- P1/P2/P3 nuevos son `type: CLIENT`.
- Todas las consultas usan `parse_evtx()`.
- TEC-009 se detecta principalmente por PowerShell 4104:
  - herramienta HTTP;
  - `-InFile`;
  - `POST`;
  - `application/zip` o `.zip` o `upload`.
- Sysmon ID 3 queda como contexto, no condicion obligatoria.
- TEC-008 no depende de Sysmon ID 23/26.
- TEC-007 no depende solo de Sysmon ID 11.
