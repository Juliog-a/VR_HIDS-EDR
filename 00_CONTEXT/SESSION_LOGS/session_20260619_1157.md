## Bugs detectados y corregidos

1. Windows PowerShell 5.1 podía lanzar `Los tipos de argumentos no coinciden`
   al convertir directamente `Generic.List` con `@(...)`; se normalizó con
   `.ToArray()`.
2. `ParseFile()` podía interpretar una `Ó` mayúscula UTF-8 sin BOM como comilla
   tipográfica bajo Windows PowerShell; los mensajes de estado del validador se
   dejaron en ASCII para garantizar parser 5.1.
3. FP-009 dependía de un listener externo y podía quedar `SKIPPED`; el wrapper
   crea un `TcpListener` benigno controlado en `127.0.0.1:80`.
4. El benchmark habría reutilizado exfiltración real; se añadió un lanzador de
   carga específico con `EnableExfilUpload=false`.
